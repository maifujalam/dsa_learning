Block Storage:-

Cloud Disks:
- Gives feature of multili attach otion.
- Gives disk encryption using KMS,like default Cloud Managed Key (CMK).
- Survices instance live cycles:- stop,restart,release.
- Used for database,production data,critical applications.

Local Disk:
- Disks that are directly attached to the physical servers where ECS instance is running.
- High random IO,high throughput and ultra low latency.
- Used for high performance systems like:- cache servers like- redis,mongodb,elastic hot data.
- Datamay loose of the host is corruppted.


Ephemeral Disks:-
- High IOPs used to store temporary data.
- Released when instance is released.
